## Direction contract

THESIS: Every job and application becomes a travel document — a boarding-pass-style match card, a coupon-book Pipeline where one leg tears per stage, nothing deleted only VOIDed — refusing the generic SaaS card-grid every job tool defaults to.

OWN-WORLD: Coupon-white ground, Carrier Navy structure, Jet Red as the one committed working accent (30–60% via headers, primary actions, live-status chips), Carbon Purple reserved for duplicate-sighting/"carbon copy" states, a diagonal red VOID stamp for closed/rejected. Big Shoulders Display (condensed caps) for headlines and flight-style labels, IBM Plex Sans for body/UI labels, IBM Plex Mono for tabular numerals (scores, dates, salaries) set as carbon-copy figures. Ticket-stub card shapes with perforated/torn edges, hairline rule dividers, tab-style section labels instead of pill badges.

STORY: The user opens Today each morning and reads it like checking a flight board before departure — one boarding-pass summary of the day, then ranked matches as segmented pass cards (Role/Company/Score/Visa as stamped fields), decides who to pursue, and watches Pipeline as a coupon wallet where each application tears off its next leg as it advances.

FIRST VIEWPORT: Today page — navy header bar with wordmark; below it a torn boarding-pass-style summary strip (118 NEW · 31 PASSED · 30 SCORED · 5 TO REVIEW) in carbon-mono tabular figures; then a stacked list of top matches as boarding-pass cards (role/company/location/score stamp/visa tag), each ending in a perforated tear-line holding Save/Review buttons; right rail holds Follow-ups due as a live-status board list.

FORM: Challenger "The Ticket Wallet" (vernacular-ephemera-jet-age-ticket-wallet), won both axes (audience identification, product clarity) against assigned "The Noticeboard Wall" in the re-rolled hand; seed key e4ec5967.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
